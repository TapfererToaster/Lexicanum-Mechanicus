>[!note]
>Java Dateien müssen den selben Namen haben wie die darin definierte Klasse mit der Endung `.java`

# Syntax
Anweisungen enden mit einem Semikolon und Anweisungsblöcke werden durch geschweifte Klammern eingegrenzt.
```java
public static void main(String[] args)
{
	Anweisungen;
}
```

## Kommentare
Um ein Kommentar in Java zu schreiben benutzt man `//` für einzeilige Kommentare und `/* ... */` für mehrzeilige Kommentare.
```java
// Einzeiliger Kommentar

/* Kommentar über 
mehrere Zeilen */
```

## Variablen 
Java ist eine statisch typisierte Sprache, bei der Deklaration von Variablen muss also der Datentyp angegeben werden.
```java
int i = 5;
String name = "Marco";
```
