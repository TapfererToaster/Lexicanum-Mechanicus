# Denial of Service (DoS)
Causes:
- **Improperly configured devices**: 
  Improper configurations can cause a network outage, f.e. faulty IP addresses or subnetmask
- **Interference**: 
  An attacker could interfere with the signal, especially wireless signals, to disrupt or disable communication between devices; it is also possible that devices that also operate on the 2,4 GHz band interfere with the signal

# Rogue Access Point
An unauthorized AP that is installed into the network. 
A cell phone connected to the WLAN and enabling a hotspot is also a rouge AP.
