# International Organization for Standardization (ISO)
Die ISO ist eine Dachorganisation von 163 nationalen Normungsausschüssen und wiederum selbst Mitglied der International Telecommunication Union - Telecommunication (ITU-T).
Die Aufgabe ist über Standardisierungen abzustimmen, diese zu vereinheitlichen und an die nationalen Ausschüsse als Empfehlungen weiterzugeben. 
Die ISO veröffentlicht Standards über Technologien.

> [!NOTE]
> The abbreviation is ISO and not IOS, because the ISO is derived from isos, Greek for "equal", as the ISO wanted one shared abbreviation that is not based on the englisch name.

# Internet Assigned Numbers Authority (IANA)
The *IANA* manages both IPv4 and IPv6 addresses and allocates blocks of them to the *Regional Internet Registries (RIR)*. 
## Regional Internet Registries (RIR)
RIRs are responsible for allocating IP addresses to ISPs, who provide address blocks to organizations and smaller ISPs.

# International Telecommunication Union (ITU)
Die ITU besteht aus drei Sektoren:
- ITU-R: Radiocommunication
- ITU-D: Development 
- ITU-T: Telecommunication

Diese geben Empfehlungen heraus, die jedoch für die meisten Länder verpflichtend sind.
Die Empfehlungen werden in Serien herausgegebe

|Serie|Thema|
|---|---|
|A|ITU-interne Organisation, Verfahrensabläufe, Gremien|
|E|Betrieb von Telefonnetzen, Adressierung, Nummerierung|
|F|Telegrafendienste, Telematikdienste, Mitteilungs- und Verzeichnisdienste|
|G|Telefonübertragung über drahtgebundene Verbindungen, Satelliten- und Funkverbindungen|
|I|Dienste integrierendes digitales Netzwerk (ISDN)|
|J|Fernsehübertragungen|
|T|Endgeräte und Protokolle für Telematikdienste|
|V|Datenübertragung über das Telefonnetz, Normen für Modems|
|X|Datenübermittlungsnetze|
# Institute of Electrical and Electronics Engineers (IEEE)
This organization defined the [[Ethernet|802.3 (Ethernet)]], in 1983, and [[WLAN#IEEE 802.11 standards|802.11 (Wi-Fi)]] standards.
## Groups
**Working groups**
Are assigned to develop specific technologies, with the two main ones being 802.3 and 802.11

| **Gruppe** | **Beschreibung**                                                  |
| ---------- | ----------------------------------------------------------------- |
| 802.1      | Internetworking                                                   |
| 802.3      | CSMA/CD, Ethernet                                                 |
| 802.11     | Drahtlose Netzwerke                                               |
| 802.15     | Wireless Personal Area Network (WPAN)                             |
| 802.15.1   | Bluetooth                                                         |
| 802.15.3a  | Ultra Wideband Wireless                                           |
| 802.16     | Broadband Wireless Access                                         |
| 802.20     | Mobile Broadband Wireless Access (MBWA), drahtlose Breitbandnetze |
| 802.21     | Media Independent Handoff Working Group                           |
| 802.22     | Wireless Regional Area Networks, drahtlose Regionalnetze          |


**Task groups**
Task group are assigned inside each working group to revise and continue the development of the original standards. 
Each task group is assigned a letter in alphabetical order (f.e. 802.3a, 802.3b, ...). Once all letters are used another letter is added and are also incremented in alphabetical order (f.e. 802.3aa-802.3az, 802.3ba-802.3.bz, ...).

| Gruppe  | Beschreibung     |
| ------- | ---------------- |
| 802.3u  | 100Base-T        |
| 802.3z  | Gigabit-Ethernet |
| 802.3ab | 1000Base-T       |
| 802.3an | 10Gbit-Ethernet  |
| 802.3ba | 100Gbit-Ethernet |
