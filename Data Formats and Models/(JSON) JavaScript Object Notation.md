```JSON
{"name":"John", "age":30, "car":null}
```

# Regeln
- Objekte bestehen aus Schlüssel-Wert Paaren `"Key": Value`, die Keys müssen immer Strings sein, die Werte können Strings, Zahlen, Booleans, Objekte und Arrays sein
- Objekte werden durch Kommas von einander getrennt 
- Arrays stehen in eckigen Klammern und sind durch Kommas getrennt
```JSON
[42, "Text", [1,2,3], {"Key": "Value"}]
```
