Antennas are used to enable wireless communication between devices.
Devices need a radio transmitter and a radio receiver tuned to the same radio frequency to allow sending and receiving information. These are often found in the form of a *Network Interface Card (NIC)*

# Types
- **Omnidirectional**
  provide 360° coverage
- **Directonal Antennas**
  focuses the radio signal in a single direction
- **Multiple Input Multiple Output (MiMo)**
  uses multiple antennas to increase bandwidth in IEEE 802.11n/ac/ax networks
